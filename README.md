# 🍃 Responsive Two Leaves Tea Website

A modern, fully responsive tea brand landing page inspired by the elegant design and visual experience of Two Leaves Tea. This project focuses on clean UI design, responsive layouts, smooth user experience, and attractive product presentation using pure HTML and CSS.

---

## 🌐 Live Demo

**Website:** https://responsive-tooleves-project-web.vercel.app/

---

## 📌 Overview

Responsive Two Leaves Tea Website is a front-end web project designed to replicate a premium tea brand experience. The website showcases featured tea products, promotional sections, brand storytelling, and responsive layouts optimized for all screen sizes.

The project emphasizes:

* Modern UI Design
* Responsive Web Development
* Clean Layout Structure
* User-Friendly Navigation
* Mobile-First Experience

## 🚀 Getting Started

### Clone Repository

```bash

```

### Open Project

```bash
cd responsive-twoleaves-tea
```

### Run Website

Simply open:

```text
index.html
```

in your browser.
